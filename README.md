# Squished Dungeon Bash

## About

Squished Dungeon Bash is a modification of Martin's Dungeon Bash, that 
adds proper display scaling, allowing it to run on terminals with far 
less available lines.

You can find the original game at [http://www.chiark.greenend.org.uk/%7Empread/dungeonbash/](http://www.chiark.greenend.org.uk/%7Empread/dungeonbash/).
